# Mi Organizador — Portafolio Web
## Victoria Alexandra Casillas Rodríguez

## Descripción
Sitio web de portafolio personal que muestra mi presentación, proyectos destacados y formas de contacto. Desarrollado como práctica de desarrollo web.

## 🛠️ Tecnologías utilizadas
- *HTML5* → Estructura de la página
- *CSS3* → Diseño, colores y estilos
- *JavaScript* → Navegación e interacción
- *Node.js* → Servidor de respaldo
